# Zaid Hack — Pink Edition

Aplicación Android 12+ para importar localmente `Zaid-Hack-v1.3.sh`, validar licencias ZH mediante HTTPS y gestionar el overlay ARM64 con root.

> El repositorio público **no incluye** el ejecutable privado embebido en el script. Debes importarlo desde el selector de archivos dentro de la aplicación.

Código fuente y compilación en la rama de desarrollo. La aplicación ejecuta un ELF ARM64 importado bajo privilegios root: importa únicamente archivos de confianza.
